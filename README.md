# lyskill｜零玉求职 Skills

面向实习、校招和社招的 AI 求职工具集。

## 当前包含

### lys-jd-decoder

把具体 JD 拆解成岗位任务、评价结果、要求层级和可证明的经历证据，严格区分 JD 原文、有限推断和仍需核实的信息。

### lys-resume-builder

先建立真实经历和证据目录，再根据具体 JD 选择最相关的证据，生成可迭代的岗位版本简历。

## 使用方式

进入 `skills/`，选择需要使用的 Skill，并将对应目录安装到支持 Skill 的 Agent 工具中。

每个 Skill 的完整说明、参考文件和必要脚本都放在自己的目录内。

## 边界

- 不编造候选人的经历、贡献和结果。
- JD 没有说明的内容会标记为未知或待核实。
- 简历只基于用户提供并确认的真实材料生成。
- 本仓库只发布当前可使用版本，不包含内部测试案例、历史迭代记录和个人求职材料。
