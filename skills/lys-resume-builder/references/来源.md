# 来源与边界

主体来自零玉指定的三份材料：《简历其实就是广告》《没实习经历应该怎么写简历》《如何区分简历包装和简历造假》。提取素材母版与投递版、可迁移经历、保持事实与贡献归属等规则，不把其中匿名网络案例当普遍招聘政策，不复制示例数字到用户简历。

- [OPM 工作分析](https://www.opm.gov/policy-data-oversight/assessment-and-selection/job-analysis/)：任务与能力联系。
- [OPM 结构化面试](https://www.opm.gov/policy-data-oversight/assessment-and-selection/structured-interviews)：行为取证，本文不宣称执行标准化面试。
- [OPM 评估设计](https://www.opm.gov/policy-data-oversight/assessment-and-selection/assessment-strategy/)：工作关联与效度证据边界。
- [哈佛简历指南](https://careerservices.fas.harvard.edu/resources/create-a-strong-resume/)：基于事实、具体和易读的表达。

理论用于约束判断，不表示本Skill已证明提高面试率。
